# **CreativeCapy Brand Guidelines v1.0**

## **01 — Brand DNA**

*This is the foundation. Every design decision should reinforce these values.*  
**Mission**  
Build thoughtful digital experiences that help businesses stand out through exceptional design, technology, and strategy.  
**Vision**  
To become a globally recognized creative technology studio known for craftsmanship, clarity, and memorable digital products.  
**Core Values**

* Craft over shortcuts.  
* Simplicity over complexity.  
* Quality over quantity.  
* Collaboration over ego.  
* Details create trust.

## **04 — Logo Usage**

**Primary Logo**  
Use for: Website, Presentations, Social banners, Marketing  
**Wordmark**  
Use for: Navbar, Footer, Website Loader, Email Signature  
**Icon**  
Use for: Favicon, App Icon, Social Profile, Watermark, Loading Animation, Merchandise  
**Stacked Logo**  
Use for: Instagram, LinkedIn, Dribbble, Behance, Posters

## 

## **05 — Clear Space**

*The logo should always have breathing room.*  
**Rule:** Minimum clear space \= height of the capy's ear.  
No text or graphics should enter that area.

| :---- | :---- | :---- |

| **Icon** | 32 px minimum | \- |

## 

## **08 — Color Ratios**

*This is important. Instead of using colors equally:*

| Proportion | Brand Color | Usage |
| :---- | :---- | :---- |
| **70%** | Dark | Dominant background/text |
| **20%** | Cream | Secondary background/text |
| **10%** | Copper | Accents |

**Note:** Copper should always feel like an accent, not the dominant color.

##

**Typefaces**

* **Display:** Satoshi Bold *or* General Sans Bold  
* **Headings:** General Sans  
* **Body:** Inter  
* **Code / Numbers:** IBM Plex Mono

**Type Scale**

| Level | Size (px) |
| :---- | :---- |
| Display XL | 96 |
| Display | 72 |
| H1 | 56 |
| H2 | 40 |
| H3 | 32 |
| Body | 18 |
| Small | 16 |
| Caption | 14 |

## **10 — Corner Radius**

*Consistency matters.*

| Element | Radius |
| :---- | :---- |
| Buttons | 14 px |
| Cards | 24 px |
| Images | 28 px |
| Tags | 999 px |

## **11 — Shadows**

*Never heavy.*  
**Example Example:** Y: 10, Blur: 40 | 10% Opacity  
**Guidelines:**

* Soft.  
* Invisible.  
* Elegant.

## 

## **12 — Grid System**

| Breakpoint | Columns | Margin | Gutter |
| :---- | :---- | :---- | :---- |
| **Desktop (1440 px)** | 12 | 80 px | 24 px |
| **Tablet** | 8 | \- | \- |
| **Mobile** | 4 | \- | \- |

## **13 — Spacing Scale**

*Everything follows an 8-point system. Never random spacing.*  
**Values (px):**  
4, 8, 16, 24, 32, 48, 64, 96, 128

## 

## **14 — Icon Style**

* Only outline icons.  
* Rounded corners.  
* 2px stroke.  
* No filled icons.

## 

## **15 — Photography**

**Always:**

* Natural light  
* Warm  
* Editorial  
* Clean desks  
* Real people  
* Texture  
* Shadows

**Never:**

* Fake smiles  
* Over-saturated  
* Blue tech lighting  
* Stock office handshakes

## 

## **16 — Illustration Style**

* Flat  
* Minimal  
* Rounded  
* Warm  
* Copper accents  
* **No** gradients.  
* **No** cartoons.

## **17 — Motion Language**

*This is where CreativeCapy becomes premium.*

| Animation | Duration |
| :---- | :---- |
| Cursor Follow | 120 ms |
| Button Hover | 180 ms |
| Card Hover | 240 ms |
| Modal | 350 ms |
| Page Transition | 600 ms |
| Hero Reveal | 900 ms |

**Motion Rules:** All animations use smooth easing. No bouncing. No elastic effects.

## 

## **18 — Voice & Tone**

| Instead of saying... | Say... |
| :---- | :---- |
| "We deliver innovative digital solutions." | "We build websites people actually enjoy using." |
| "Contact Us" | "Let's build something together." |
| "Submit" | "Start the Conversation" |

**Tone should always be:**

* Conversational  
* Confident  
* Honest  
* Clear  
* Human

## 

## **19 — UI Language**

*The website should follow these rules:*

* Large typography.  
* Generous whitespace.  
* Editorial layouts.  
* Thin dividers.  
* Rounded cards.  
* Subtle textures.  
* No unnecessary decoration.  
* One visual focal point per section.

## 

## **20 — Brand Don'ts**

*Never:*

* ❌ Stretch the logo.  
* ❌ Rotate the logo.  
* ❌ Add glows.  
* ❌ Use more than two brand colors in one component.  
* ❌ Place the logo on busy photography without sufficient contrast.  
* ❌ Use different corner radii within the same component.  
* ❌ Mix multiple illustration styles.  
* ❌ Use heavy shadows or flashy gradients.
